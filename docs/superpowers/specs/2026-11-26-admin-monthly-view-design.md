# 관리자 주간 현황: 날짜로 이동 + 월간 보기 (설계)

## 왜
원하는 날짜를 바로 찾고, 한 달 중 어느 날이 바쁜지 한눈에 보고 싶다.
처음 요청한 "달력에서 날짜를 누르면 오른쪽에 그날 예약자 목록 → 수정·삭제"를 이룬다.

## 만드는 것
- 주간 예약 현황 상단: `[주간 | 월간]` 전환, `날짜로 이동`(date input), `‹ 이번주/이번달 ›`.
  - 날짜로 이동: 주간 → 그 주, 월간 → 그 달 + 그 날 선택. 고른 날 강조.
  - ‹ › 는 주간 = 7일, 월간 = 1달.
  - 센터·공간 필터는 두 보기에 모두 적용.
- 월간 표: 일~토 7칸, 앞뒤 달 날짜는 흐리게. 칸마다 예약 최대 3개(`시간 이름`, 부서 색) + `+N건`.
- 날짜 클릭 → 오른쪽 패널에 그날 예약 목록(시간·🔁·센터·공간·이름/부서, 부서 색). 예약 클릭 → 기존 상세 창.
- 처음 월간을 열면 오늘(그 달이 아니면 1일) 선택. 좁은 화면에서는 패널이 아래로.
- 페이지는 주간으로 시작.

## 하지 않는 것
- DB·데이터 변경 없음. 주간/월간 선택 기억 안 함.

## 방식
- 검토: ① 날짜 고르는 팝업 달력(예약 표시 없음) ② 월간 예약 보기(선택). ①의 역할은 `날짜로 이동` 칸이 맡는다.
