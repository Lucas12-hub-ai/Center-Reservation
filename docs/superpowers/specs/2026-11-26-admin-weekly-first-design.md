# 관리자 페이지: 주간 현황 첫 화면 + 부서 색 + 고정예약 묶음 (설계)

## 왜
관리자가 원하는 날짜의 예약을 찾기 어렵다. 고정예약이 날짜마다 1줄씩 목록에 깔려서
6개월 고정이면 20~30줄이 된다. "그날 누가 쓰는지 보고 바로 고치기"가 주 업무다.

## 목표
1. **주간 예약 현황을 첫 화면으로**: 사이드바 맨 위 메뉴, 페이지를 열면 바로 표시.
2. **주간 표에서 바로 관리**: 예약 칸 클릭 → 기존 상세 창(수정 / 이 날짜만 삭제 / 남은 일정 삭제).
3. **부서별 색**: 글자 포함 규칙.
   - '신학' 또는 '산학' 포함 → 보라
   - '청년' 포함 → 초록
   - 그 외 → 회색
   - 규칙은 코드의 표 하나(`DEPT_COLORS`)에 모아 한 줄 추가로 늘릴 수 있게.
   - 주간 표 위에 색 범례 표시.
4. **고정예약 표시**: 주간 표 칸에 🔁 표시.
5. **예약 목록(기존 '예약 관리')에서 고정예약 묶기**: 같은 `recurring_group_id`는 한 줄.
   - 날짜 칸: `2026.11.26 (목) ~ 2027.02.25 (목)`, 유형 칸: `매주 목 · 총 14회`.
   - 필터(날짜·센터·공간·예약자·목적·유형)는 묶음 안 날짜 중 하나라도 맞으면 그 묶음을 보여준다.
   - 클릭 → 다음 예정일(없으면 마지막 날짜)의 상세 창. 묶음 전체 삭제·개월 변경은 기존 기능 사용.
   - 건수 제목과 페이지 나눔은 묶은 줄 기준.

## 하지 않는 것
- DB 구조 변경, 예약 데이터 변경 없음 (화면만 바꿈 → Telegram 알림 영향 없음).
- 월 달력 화면 추가 안 함 (주간 표로 대체하기로 함).
- 부서 색을 관리자가 설정하는 화면 없음.

## 방식 (검토한 것)
- 부서 색: ① 글자 포함 규칙(선택) ② 이름마다 자동 색 — 같은 부서 이름이 제각각이라 색이 갈림 ③ 설정 화면 — 작업량·DB 저장 필요.

## 제약
- 바닐라 JS 단일 페이지(admin.html / admin.js / admin.css). 새 라이브러리 없음.
- 엑셀 다운로드는 지금처럼 날짜별 개별 행 유지 (빌더 판단).
- 기존 오늘 예약·센터별·통계·문의·설정 화면은 그대로.
